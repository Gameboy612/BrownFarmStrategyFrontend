This is a player-made LINE Brown Farm Strategy Wiki Website. It is a static website hosted on GitHub Pages.
The website is designed to provide information and resources about the LINE Brown Farm Strategy.

# Pages
- Home: The main page of the website, providing an overview of the LINE Brown Farm Strategy.
- Tips: A page dedicated to tips and strategies for playing the LINE Brown Farm game effectively.
- Resources: A page that lists various resources, such as guides, videos, and tools related to the LINE Brown Farm Strategy.

# Architecture
The website is built using compiled Next, which allows for fast and efficient rendering of the pages. The static files are generated and hosted on GitHub Pages, making it easy to deploy and maintain the website.

The overall theme of the website should be stemmed from the same file, meaning changing one file could change the entire website's theme. This allows for easy customization and consistency across all pages. Make it similar to a game wiki style.

The color scheme should be:
--text: #060908;
--background: #fbfcfc;
--primary: #ceaf6d;
--secondary: #d3b989;
--accent: #b4a397;

Use tailwind css for styling the website.
Rectangular style, no rounded corners, and a clean, modern design should be implemented to give the website a professional and user-friendly appearance.

The website is mainly in Traditional Chinese, find related LINE photos online to use as icons and images on the website. Make sure to properly credit the sources of the images used. 

The website is available in Chinese, English, and Japanese, a language switcher is implemented to allow users to easily switch between languages. The content on the website is translated into all three languages to cater to a wider audience.
