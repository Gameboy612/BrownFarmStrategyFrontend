通常無課玩家玩都遇到兩個問題
1. 要不就是鑽石不夠用
2. 要不就是鑽石囤積不知何時使用


有些玩家提議盡快開夥伴門，
但我個人認爲這不是最優策略。
因爲夥伴門升級成本高，
且初期並不急需大量夥伴。

## 以下是我個人建議的無課鑽石使用策略：
1. 優先升級 **麵包** 和 **牛奶** 建築，至少升到4格，最好6格。這兩種建築是遊戲初期最重要的資源生產建築，升級後可以大幅提升資源產量，幫助你更快完成任務和升級其他建築。
![Dairy Shop 6 Slot](/images/shared/blogs/gems-strategy/dairy_shop_6_slot.png)

2. 升級 **朋友商店格數**，每格5鑽石。朋友商店可以用作長期貨倉，能擺放30個物品，且不會過期。小心如果賬戶有很多好友，有機會被不認識的好友買掉物資，建議只加認識的好友，並且有共識才這樣使用好友欄。
![Friend Slot](/images/shared/blogs/gems-strategy/friend_slot.png)

3. **20/40/60 鑽石抽獎活動**。有些活動會提供抽獎機會，使用極少鑽石就能夠抽小夥伴。建議儘量參與這些活動，以低價獲得小夥伴。

4. **補鑽石以獲得鑽石**。有時有些活動可能差3-5鑽石就能完成活動/任務獲得6+鑽石，可以直接補鑽石完成任務，獲得更多鑽石獎勵。

## 中後期可以考慮以下使用策略：

5. 基礎素材商店可考慮升級爲9格，飼料4格+5格，其他普通商店可考慮升級爲4格。

    | 基礎素材 (9格) | 常用物資（4-6格） |
    | - | - |
    | 奶油店 | 麵包店 |
    | 砂糖店 | 魚餌店 |
    | 醬油店 | 飼料店 (4+5格) |

<br>
<br>

6. 小夥伴門，中期開始小夥伴可以自動生產資源，節省不少時間。同時滿等小夥伴可以讓抽角色試不會抽到重覆的小夥伴，增加抽到新小夥伴的機會。

7. 圖騰洞穴：適合儘早升級，早買早享受，能把製作時間減低20%，適合奶油店、砂糖店等等。
![Totem Cave](/images/shared/blogs/gems-strategy/totem-cave.png)

8. (悠閒玩家) 抽限定聯名小夥伴。有時玩遊戲不過是想享受過程，抽限定聯名小夥伴也是一種樂趣。建議在有特別喜歡的聯名小夥伴時，可以考慮使用鑽石抽獎。
